# The Gaze of Naiwa（dsh-the-gaze-of-naiwa）

右上角附近的一枚圆形毛玻璃头像，可自由拖动，跟着当前会话的智能体状态切换：

- **空闲**：侧脸头像（新图二），轻微呼吸缩放。
- **思考**：托腮头像（新图一），冷色柔光环绕，右上角毛玻璃三点气泡。

点击头像会冒出一句深色毛玻璃气泡；鼠标悬停有状态提示。全部界面文字走 DSH locale（中文／英文）。

## 状态来源

Client 半从 `ctx.get('uiSession')` 读取：

- `uiSession.current`：主视图当前绑定的会话；
- `uiSession.sessionStatus`：该会话的 `running` 标记。

两者都变化时重新取快照，因此新建会话、切会话、发出消息、任务结束都会立即反映到表情上。打开设置页（Conversation 卸载）时会记住最后一个主会话，不会误判为空闲。没有 `uiSession` 服务时退化为永久空闲，不影响页面其他部分。

## 尺寸与缩放

不再写死 160px，而是按视口自动缩放：

```css
--naiwa-size: clamp(120px, 18vmin, 250px);
```

- 大小约为**视口短边的 18%**，最小 120px、最大 250px；窗口缩放、浏览器缩放都会连续变化。
- 圆盘、光晕、投影都跟随这个尺寸，不再依赖固定的 120/160 断点。

## 调整大小

- **右键头像**打开毛玻璃大小菜单。
- 滑杆范围 **70%–150%**，下方有 `80% / 100% / 120%` 三个快捷档位，顶部实时显示百分比。
- 调整时以头像中心为锚点，尽量保持原位；大小保存在 `localStorage`（`dsh-the-gaze-of-naiwa:scale-v1`）。
- 点击菜单外或按 Esc 关闭，`完成` 按钮也会收起菜单。

## 拖动与位置

- 整个圆形头像就是拖动柄：按住拖动即可，鼠标/触屏都支持，边距自动限制在窗口内。
- 默认落在**右上区域**（右侧 18px、约视口高度 20% 的位置），不会压住顶部导航栏。
- 拖动超过 4px 才算拖动，轻点仍然只弹气泡；拖动结束会自动保存位置。
- 位置以**比例**保存在 `localStorage`（`dsh-the-gaze-of-naiwa:pos-v1`），窗口大小变化后仍保持相对位置。
- 气泡会根据当前位置自动翻转：在下方时向上弹，在左侧时向右弹，不会跑出窗口。

## 头像与质感

- 只保留**头像/半身特写**，不再显示整张全身图；两张图分别裁到头部，头/脸占满圆形视野。
- 思考图保留托腮的手，空闲图保留侧脸和少量颈部/肩部。
- **单层**：没有内外两层容器，头像直接铺在圆形玻璃盘上；只有一层圆。
- 玻璃盘：`backdrop-filter: blur(22px) saturate(150%)`、冷白半透明底、1px 白色高光边、内外柔和阴影、极淡噪点纹理和左上角高光。
- 已移除右下角颜色状态点；状态只由头像、思考光晕和三点气泡表达。
- 没有橙色边框或橙色点缀；深色主题自动切换深色玻璃底。

## 结构

| 文件 | 作用 |
| --- | --- |
| `client.js` | 浏览器半：注册 `shell.overlay` 条目、状态源、React 组件与毛玻璃样式。 |
| `assets/idle-d8539753.png` | 空闲头像特写（640×640，新图二）。 |

| `icon.png` | 插件管理页图标（新头像头部特写 + 圆形玻璃）。 |

## 素材

头像素材由用户提供；只做了头部裁切、等比缩放、居中与轻微锐化，没有拉伸。插件本身不引用任何外链图片。

## 安装

```powershell
dsh plugin --profile desktop add "file:C:\path\to\dsh-the-gaze-of-naiwa-1.0.7.tgz"
```

或把 `.tgz` 直接交给 profile 的插件管理器安装。

## 说明

- 头像用 `overflow: hidden` 裁成正圆；光晕、状态气泡可以溢出圆外。
- 所有动画都遵守 `prefers-reduced-motion`。
